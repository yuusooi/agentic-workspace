二、关闭集群
方法1：逐个关闭窗口（推荐）
按顺序关闭：

先关 mongos 窗口 (13-15)

再关 分片窗口 (4-12)

最后关 配置服务器窗口 (1-3)

方法2：一条命令关闭所有
powershell
# 在 PowerShell 中执行
Get-Process mongod, mongos | Stop-Process -Force

四、常用维护命令
在 mongos 中执行
查看集群状态

javascript
// 查看所有分片
use config
db.shards.find()

// 查看数据库
db.databases.find()

// 查看集合分片情况
db.collections.find()
查看数据分布

javascript
// 切换到你的数据库
use test

// 查看集合统计
db.users.stats()

// 查看数据总量
db.users.countDocuments()
分片操作

javascript
// 启用数据库分片
sh.enableSharding("数据库名")

// 创建分片集合
sh.shardCollection("数据库名.集合名", { "分片键": "hashed" })

// 查看分片状态
db.printShardingStatus()
五、配置文件修改
如果将来需要修改配置（如增加内存、修改端口），可以在启动命令中添加参数：

powershell
# 常用参数
--bind_ip 0.0.0.0        # 允许远程连接
--maxConns 1000          # 最大连接数
--wiredTigerCacheSizeGB 1 # 限制内存使用（单位GB）

# 示例：带参数的启动命令
.\mongod.exe --shardsvr --replSet shard1 --dbpath D:\mongodb-win32-x86_64-windows-8.2.6\data\shard1\1 --port 27001 --bind_ip 0.0.0.0 --wiredTigerCacheSizeGB 1
